TEE SUPPORT

Help

Refresh / Update TEE

  1. Tap Refresh / Update.
  2. TEE refreshes only cached app files and reloads.
  3. Confirm the newest version appears.

This does not intentionally clear Vault records, passphrases, expenses, notes, localStorage, or IndexedDB.

Install on iPhone

Tap Install → Copy Instructions. Send the message. Recipient opens the link in Safari → Share → Add to Home Screen.

New or replacement phone

Choose Restore Existing TEE, select the authorized encrypted backup, then unlock the Vault. Do not create a replacement vault.

If an old version remains

Use Refresh / Update first. Do not clear all Safari Website Data merely to update TEE; that can remove locally stored Vault data.

Privacy
