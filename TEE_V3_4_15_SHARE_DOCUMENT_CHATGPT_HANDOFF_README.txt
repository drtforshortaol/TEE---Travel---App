TEE v3.4.15 — Share Document to ChatGPT

Purpose
- Make the online ChatGPT document-reading path practical on iPhone.

Traveler workflow
1. Add Document.
2. Continue to Review.
3. Tap Analyze with ChatGPT.
4. When Web Share is available, TEE opens the device Share sheet with the selected document(s) and copies the exact TEE analysis request. Choose ChatGPT.
5. In ChatGPT, send/paste the request if needed.
6. Copy the returned JSON result.
7. Return to TEE and tap Paste Results.
8. Verify every proposed field against the original before Save to TEE Vault.

Fallbacks
- If direct file sharing is not available, TEE copies the request and opens ChatGPT; attach the document manually.
- If clipboard reading is blocked, use Manual Paste — if clipboard does not work.
- Offline option — Local OCR / MRZ remains available.

Privacy
- TEE never sends a private document to ChatGPT automatically. Sharing occurs only after Analyze with ChatGPT is tapped.
- Vault and archive protections are unchanged.
