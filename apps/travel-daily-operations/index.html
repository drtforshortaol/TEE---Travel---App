Core Phase 1

Daily Mission Control

Use this section first each morning, the night before a transfer, and whenever the day starts to drift.

Today

  • Confirm city, hotel/base, main activity, transportation, weather, and cash/tip needs.
  • Check the matching daily card below before leaving the room.
  • Use notes for last-minute private updates.

Tomorrow

  • Pack/repack before bedtime if tomorrow is a move day.
  • Confirm pickup, train, flight, hotel check-in, and tickets.
  • Charge devices and stage passport/wallet/phone.

Next Movement

  • Review transportation app before every transfer.
  • Keep confirmations in Private Documents.
  • Leave buffer time for luggage, bathrooms, snacks, and screenshots.

Problem Log

  • Write delays, missing items, aches, hotel issues, and plan changes in the day note.
  • Use the adaptive checklist for new tasks that must not be forgotten.
