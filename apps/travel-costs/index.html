Encrypted Expense Archive

Creates a protected .tee49 archive containing the currently authorized expense records and stored receipt attachments. The archive uses the currently authorized couple's existing TEE passphrase—there is no separate archive password.

Before final export: import the latest Shared Expense package from the other phone first. To preserve each couple's Private expenses, each couple should create its own authorized archive while logged in with its own passphrase.

Shared Expense Exchange

Phone-to-phone sharing

Shared expenses can move between the two iPhones in an encrypted package. GitHub is used only for a small update beacon; it never receives the expense contents.

1. Send Shared Expenses

Unlock protected expenses first, then export the Shared ledger. Test expenses are excluded unless you choose to include them.

Transfer code

Send the downloaded .tee46 file directly to the other iPhone. Send the transfer code separately if possible.

2. Receive Shared Expenses

Select the encrypted package received from the other couple, enter its transfer code, and let TEE merge the records.

3. Check for an Update

When TEE is hosted on GitHub Pages, it can read a tiny beacon file and tell you whether a newer Shared expense package is available.

No beacon checked yet.

The beacon contains only package/version metadata. The actual expense package still travels phone-to-phone.

Costs Protocols

Useful trip rules

Capture now, organize later

Photograph or paste the expense while it is fresh. Add enough detail to recognize it later.

Shared vs Private

Use Shared for expenses both couples need to see. Use Private for one couple's personal spending or financial notes.

Receipts

TEE automatically reduces large receipt photos before storing them. PDFs must remain small enough for local browser storage.

Test entries

Mark trial expenses as Test. Filter them later and delete them individually or with Delete Visible Test Expenses.

Backup

Protected expenses become part of the encrypted vault and should be included whenever you make a current vault backup.
