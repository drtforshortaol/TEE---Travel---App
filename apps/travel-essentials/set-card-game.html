SET Card Game

Offline quick instructions, play sequence and visual examples.

The one rule to remember

A SET is 3 cards where, for each feature, the three cards are either all the same or all different.

If two cards are the same and the third is different in any feature, it is not a SET.

The 4 features

Shapeoval · squiggle · diamond
Colorred · purple · green
Number1 · 2 · 3
Shadingsolid · striped · open/outlined

How to play

  1. Shuffle and lay 12 cards face up in a rectangle.
  2. Everyone looks at the same time. There are no turns.
  3. When you see a SET, call “SET!”.
  4. Show the 3 cards. Other players check the SET.
  5. If correct, keep the 3 cards for 1 point and replace them with 3 new cards from the deck.
  6. If all players agree there is no SET among the 12 cards, add 3 more cards. When a SET is found, do not replace those 3 extra cards; reduce back toward 12.
  7. Play continues until the deck is depleted and no SET remains. Each SET = 1 point; high score wins.

Calling SET without having one, or showing an incorrect SET, carries the penalty described in the printed rules: loss of one point and return of the cards to the table.

Easy start

For a quick introduction, use only the solid-symbol cards. This removes shading as a feature. Once players are comfortable with 3 features, shuffle the decks together and play the full 4-feature game.

Quick non-SET check

If, for example, two cards are purple and one is green, that feature is neither all the same nor all different — so those 3 cards cannot be a SET.

Fast mental test: for every feature ask, “same, same, same — or different, different, different?” If the answer is neither, reject the trio.

Solitaire variation

Play alone using the same 12-card layout. If you cannot find a SET, add 3 cards but take a one-SET penalty. To win, you must later erase that penalty by finding a SET among the final 12 cards.
